Jev Playground

Evaluation API

Jev is TypeSafe's System One decision model. Give it a shared state and typed questions, and it returns calibrated choice, score, and boolean / noul answers your code can act on directly. No prose to parse.

Presets

Input

Configure TYPESAFE_API_KEY or AI_GATEWAY_API_KEY on the server or in the Admin Dashboard.

choiceWhich one?

        
Pick one option from a set you define. Returns the winning option, plus probabilities and confidence when available. Add an other option when the set might not cover every input.

      

      

        
scoreWhere on this scale?

        
Rate the state along ordered levels (low to high). Returns a fractional score between levels, plus probabilities when available, for thresholds and averaging.

      

      

        
boolean / noulIs this true?

        
A yes/no judgment. Returns the probability of yes from 0 to 1. Optional true / false criteria clarify what each end means.

      

    


    

      
Two things to keep in mind

      
    
        
  • State is text or JSON, not images. Describe screenshots, documents, or observations as structured data before asking Jev about them.
    • 
        
  • Ask snap judgments, not multi-step reasoning. Each question should be one atomic decision. Compose several small questions in your code instead of asking one big question.
